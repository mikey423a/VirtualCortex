# Virtual Cortex 6.27 routing

Custom routing now selects a first processed slot A–H per row and an independent source tap for each earlier row. A tap is Before A or After A–H. This supports splits after an amp/cab, branches that start partway through another row, and merges of branches tapped at different columns. Each active physical slot executes once per stereo frame. Empty and bypassed slots preserve their boundary signal. Slots before a destination entry are skipped, dimmed and labelled SKIPPED in the expanded grid.

Source taps include the source row gain, stereo balance and polarity. OUT still sends the row's end signal to the final mix. Average or unity summing retains its previous behavior. Templates reset to Start A and After H; old presets default to those same settings. Tap and entry settings stay attached to physical row/column positions when devices move. Save the preset to retain changes.

Example: put an amp in row 1 C; row 2 and row 3 select source 1 / After C. Set their Start controls to the first desired effect. Set row 4 to sources 2 and 3 and select each desired tap. Turn OUT off on rows 1–3 and on for row 4. Row 1 can continue processing its remaining slots, but its later signal does not affect a branch tapped at C.

Scope: routing remains a forward graph from earlier rows into later rows, with one entry point per destination row. It does not yet provide multiple injection points in one row, backward/cyclic wires, drag-to-connect wires, hardware multichannel buses, scene routing or DAW automation. Global post effects still follow Custom mode. Topology changes are immediate; only gain, balance and polarity use the existing smoothing. Skipped processors are not advanced, so their tails do not run while skipped.
