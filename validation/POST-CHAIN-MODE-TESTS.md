# Final-output routing transition regression

This test-only follow-up to 6.45 compares two native processors with Stereo Delay and Stereo Reverb active. A sustained stereo signal switches from Parallel to Custom with a -12 dB row gain. The fixture compares the first switched sample on both channels, asserts identical output before the switch, and checks energy after the input stops. Windows verification pending. The delivered 6.45 application is unchanged.
